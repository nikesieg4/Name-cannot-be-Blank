# U-Boot/Schiffe Versenken

Person: 2d, 3te Person

Handel: Man ist auf einem Uboot welches man von einer seitenansicht sieht wo man reinzoomen kann und ziehen kann und man soll einzelne crewmitglieder anklicken können und bewegen können also befehle geben können. Das Ganze soll in dem Stil von False echo einem Early access game auf steam sein. Man spielt als Geheimdienst offizier in diesem spiel soll man als Hauptman spielen und man gibt die Befehle. An den Seiten ist UI wie Statistiken (Geld, Moral, Essen usw) und auch steuermittel wie etwas wo man die Tiefe auswählt also Maximal Sichere Tiefe, Seerohr tiefe usw

Werte:
  Moral: Entscheidet wie motiviert die Leute sind und wie schnell sie aufgaben machen. Wird beeinflusst davon wieviel essen die Crew bekommt und wieviel schlaf
  Geld: Wird Verwendet um upgrades im Hafen zu kaufen und zu Handeln mit anderen Schiffen.
  Essen: Rationen an bord. Man gibt an wieviel man jeden Tag verwenden möchte, die Crew ist das dann (es gibt ein Maximum und ein Minimum).

Es soll als Webgame funktionieren ohne Datenbank also man downloaded seine Savefiles selber (die sollen sicher gemacht werden gegen Manipulation)
